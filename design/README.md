# 日格交互原型

此原型用于评审 v0.1 的普通日历、彩色事项和助手修改确认流程。它是单文件浏览器演示，不是正式桌面程序，没有真实 MCP 服务、SQLite 或文件保存。

[打开原型](index.html)。可直接用浏览器打开本地文件，不依赖第三方 CDN、字体或联网资源。示例日期固定为 2026 年 10 月，演示“今天”为 10 月 11 日；页面刷新会恢复示例数据。

![日格月历设计](preview.png)

## 可操作的内容

月份切换、选日期、添加标题与备注、选择六种颜色、修改日期与颜色、完成与恢复未完成、搜索、修改记录、模拟助手暂停、修改预览、拒绝与确认。

手动删除使用演示确认并移出内存列表；正式版本的软删除、恢复、撤销、备份、授权凭据和 MCP 协议按研发文档实现。连接页清楚标为模拟，不建立真实外部连接。

## 本轮走查记录

走查日期：2026-10-11；浏览器：Tabbit；本地预览地址使用 127.0.0.1。以下只代表原型交互通过。

| 场景 | 实际结果 |
| --- | --- |
| 10 月 14 日添加红色事项 | 月历与日期面板显示同一标题、备注和颜色 |
| 将该事项移到 17 日并改紫色 | 14 日清空，17 日显示新颜色 |
| 完成该事项 | 月历含勾号与完成样式 |
| 搜索标题 | 返回 17 日事项 |
| 拒绝模拟助手修改 | “提交材料”仍在 15 日，橙色 |
| 确认模拟助手修改 | 移到 16 日，紫色；历史显示模拟助手 |
| 刷新页面 | 恢复初始示例，符合不持久保存的演示约定 |
| 1280×820 布局 | 日历完整显示，文档滚动尺寸 1280×820，无横向或纵向溢出 |
| 960×640 布局 | 日期面板为可关闭抽屉，选日后打开；无横向溢出 |
| 六色文字对比 | 按 sRGB 相对亮度计算均超过 4.5:1，最低约 5.37:1 |

未通过原型验证的正式能力：真实 MCP 联调、本地数据持久化、备份恢复、幂等与并发、VoiceOver、安装签名和升级。验收方案已为这些能力单独设置测试与发布门槛。

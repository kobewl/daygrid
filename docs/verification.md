# 验证记录

记录的是运行证据，不代表完整 v0.1 验收。0.2.0 在 2026-10-11、macOS / Apple Silicon、Rust 稳定版、Node 22、pnpm 10.33.2 上验证。0.1.0 的记录保留在文末。

## 0.2.0

### 自动检查

- `pnpm check`：版本一致性（7 处）、`cargo fmt --check`、`clippy --all-targets -D warnings`、TypeScript 类型检查、前端生产构建全部通过。
- `cargo test -p daygrid`：18 项通过。
  - `storage`（3）：幂等回放、版本冲突、软删除恢复、分页失效、只读与暂停。
  - `approvals`（7）：删除先待确认、批准后仅执行一次；过期版本与权限拒绝；暂停连接使待确认请求作废、过期处理；严格模式下所有写入走确认；活动审计只记录已知连接；搜索 / 概览 / 筛选；幂等摘要与参数键序无关。
  - `maintenance`（5）：契约与代码不漂移、拒绝来自未来的数据库、v1→v2 迁移并保留 `*.pre-v2.bak`、备份一致性与清理、10000 条数据性能基线。
  - 其余 3 项为单元测试。
- `pnpm test:mcp`：官方 Rust SDK 3.5.1 通过真实子进程 stdio 访问桥接与隔离 SQLite；工具、资源、提示词列表，创建/幂等/移动/完成，删除进入待确认并由桌面通道批准后生效，暂停后旧连接立即拒绝。协商协议 2025-11-25。
- `actionlint`：release.yml 与 ci.yml 零告警。

### 性能基线（10000 条事项，release 构建，测试进程内测量，不含 IPC 与界面渲染）

| 操作 | 耗时 |
| --- | --- |
| 一个月视图范围（约 840 条） | 0.31 ms |
| 全年月概览 | 17.5 ms |
| 全局搜索（命中少） | 15.4 ms |
| 全局搜索（全表扫描未命中） | 16.0 ms |
| 界面轮询 `desktop_pulse` | 0.02 ms |

这些是单次本机测量，用于发现数量级退化，不是 SLA。

### 升级路径

用真实的 0.1.0 二进制创建数据，再以 0.2.0 启动：旧服务被自动替换，数据库迁移到 schema v2，迁移前生成 `*.pre-v2.bak`，原有事项与历史完整保留。

### 界面交互（Chrome + 浏览器预览后端，puppeteer-core 脚本）

28 项检查全部通过：快速添加、完成切换、删除与撤销、拖拽改期与撤销、键盘导航、命令面板（搜索与日期跳转）、编辑版本冲突（载入最新版本 / 用我的草稿覆盖）、批准确认、历史恢复与筛选、主题 / 周起始 / 确认范围设置。1280×820 与最小窗口 960×640 两种尺寸的布局均已截图核对。

局限：这些交互跑在 Chrome 与内存演示后端上，不是 Tauri 的 WKWebView。拖拽使用合成事件，原生窗口里的拖拽未做自动化验证。

### 原生应用

- release 构建成功（`.app` 约 17.4 MiB），ad-hoc 签名通过 `codesign --verify`，包内含 `daygrid-desktop`、`daygrid-service`、`daygrid-mcp`。
- 在隔离数据目录启动：应用存活，日志记录 `desktop started version="0.2.0"`，界面启动后拉起隔离的服务，数据库、锁、套接字、日志与每日备份均被创建。
- 日志核对：不含事项标题或备注。
- 未做：在 WKWebView 中逐项重走上述 28 项交互。
